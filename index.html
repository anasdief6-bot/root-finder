NUMERICAL ROOT FINDER

Fixed Point Iteration · xₙ₊₁ = g(xₙ), stop when |xₙ₊₁ − xₙ| < ε
The equation to solve: f(x) = 0
Entered separately – use the g(x) from your lecture notes.
Between 1 and 10,000
Enter f(x), g(x) and x₀, then press START CALCULATION – or press EXAMPLE to load a ready-made problem.

How it works

A fixed point of g satisfies g(x*) = x*. To solve f(x) = 0 we rewrite it as x = g(x) and iterate from a starting guess x₀:

xₙ₊₁ = g(xₙ), n = 0, 1, 2, …

Each step computes the error |xₙ₊₁ − xₙ| and stops when it is below ε. The residual |f(root)| is reported as an independent check: a fixed point of g is a root of f only if g was derived from f. If |g′(x*)| < 1 the iteration converges (the error shrinks by about |g′| per step); if |g′(x*)| > 1 it diverges. The original function f and the iteration function g are separate inputs, so you can enter the exact g from your lecture.

Allowed in expressions: + − * / ^, sin cos tan asin acos atan sinh cosh tanh exp ln log log10 log2 sqrt abs, constants pi and e. Implicit products such as 2x are accepted.
